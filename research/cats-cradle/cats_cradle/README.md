# 翻绳 · Cat's Cradle 手影模拟

基于 MediaPipe Hands 的交互式网页应用，用霓虹光绳复现传统翻绳图案。

## 运行方式

1. 在浏览器打开 `index.html`
2. 允许摄像头权限
3. 举起双手，顶部面板切换图案和颜色

## 注意事项

- 需要 Chrome / Edge / Firefox / Safari 现代浏览器
- 需要摄像头权限
- 页面使用 CDN 加载 MediaPipe，首次加载需要联网
- 建议在光线充足、背景简洁的环境下使用

## 功能

- 双手手部追踪
- 五种翻绳图案：星星阵 / 满天星 / 古老翻绳 / 金井翻绳 / 花局
- 霓虹颜色切换
- 发光强度、物理弹性、线条数量滑块
- 隐藏摄像头模式
- Web Audio 音效
- Verlet 物理模拟
