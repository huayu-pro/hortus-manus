## 1. 通用外壳（三支视频共享）

三支视频都是**同一个产品的不同版本/不同场次**（地址栏 `localhost:3336 / 3337 / 3341`，浏览器窗口 1728 或 1152 宽，Windows 任务栏可见）。共享骨架：

1. **全屏摄像头画面**铺底（`object-fit: cover`，镜像），无边框、无导航条。
2. **顶栏胶囊（capsule）**：屏幕上方居中偏右的一条纯黑圆角药丸（实测 `#151516` 附近，圆角半径≈高度一半），高约屏幕 5.4%，宽约屏宽 22%–52%（随文本长度变化）。
   - 左端：手势状态 emoji（`🖐`/`✋`/`🖐🖐`/`🪢`/`🌀`），随后是**当前模式/状态中文名**，`|` 分隔，然后 `● 风格名`（红白/金色）、`| X切换风格 |`，再一行 `NNfps·NNms`（小号灰白）。
   - 右侧：**7 个色点**（黄、淡黄、洋红、青、橙、绿、红）+ 最右一个**深红圆形「清空/垃圾桶」按钮**。色点是**风格/配色选择器**，当前选中项有白色外环（帧 f481 可见第二点带白环）。
   - 胶囊是**两行**：上行文案 + 下行 fps/ms 读数；`需要两只手做相框手势` 这类提示会把两行压成一行并**加宽胶囊**。
3. **左上角圆形返回键**：深色圆（≈屏幕高 7%），内含品牌 glyph（三支视频 glyph 不同：漫画框版是方块/框形，星系版是旋涡，翻绳版是∞绳结）。点击语义 = 返回/主页。
4. **左下角日志终端**：半透明黑底、等宽字体、逐行带 `[HH:MM:SS]` 时间戳 + emoji 分类色标，最新行在底部，**行数只增不减**（至少可见 11 行）。这是产品最独特的"工程感"UI。
5. **键盘提示常驻在日志里**：`🖊 就绪! Q/W/E/R 切换模式 | D 切换视图 | C 清屏`。
6. **鼠标指针可见**（视频里是真实鼠标操作，不是纯手势 demo）。

**读出的机制**（对产品的直接价值）：

- 日志是**事件流**，不是装饰：每条 = `时间 + 分类 + 事件`。分类固定几色（红=风格、黄=手势、青=模式、绿=系统成功、黄=加载、紫=权限请求）。
- **`切换模式 → undefined` 是真实 bug**：模式名查找失败时打印 `undefined`，说明模式表是 `name→label` 映射且缺少兜底。产品侧必须**禁止 undefined 泄漏**（contract §12 不伪造数据）。
- `Q/W/E/R 切换模式 | D 视图 | C 清屏` 与 contract §4 键盘语法完全同构（Q/W/E/R 是旧版四模式键，1–7 是新版）。
- 摄像头初始化顺序：`请求摄像头 → 摄像头就绪 640x480 → 加载 MediaPipe 手部模型 → 模型加载成功 → 就绪`。**权限请求在模型加载之前**，且分辨率写进日志（`640x480`）。这三步对隐私仪式（B13）有直接参考价值：日志天然是"我在做什么"的透明叙事。
- 时间戳跨视频不同（21:04 / 21:05 / 17:49），说明三支是**不同录制**，不是一次录制的剪辑。

## 2. 模式逐段拆解

### 2.1 漫画框 / COMIC FRAME（`BV1WJjF67Eky`）→ 映射 `frame`

**顶栏证据**：`strips/BV1WJjF67Eky-capsule-final.jpg`（帧 f38/f465/f481/f645/f685/f753/f805）

- `🖐 漫画框已就位 | ● 红白 | X切换风格 | 14fps·70ms` —— 已就位态。
- `需要两只手做相框手势 | 12fps·130ms` —— 未就位态（**胶囊变宽、单行、无风格段**）。
- 风格名两值：`红白`、`金色`。色点选中环在第 2 点（淡黄）时 = 金色。

**视觉行为（证据帧）**：

- `evidence/comic-frame-BV1WJjF67Eky-f00038.jpg`：两手食指+拇指围成一个**四边形"画框"**，框内是**红色调（红白双色调）**的实心四边形，**边缘是洋红色虚线（dashed）**，框外是正常摄像头画面。
- `evidence/comic-frame-BV1WJjF67Eky-f00481.jpg` / `f00465.jpg`：框缩小、变形为三角形，说明框的四个角**实时跟随四指指尖**，不是固定矩形。
- `evidence/comic-frame-BV1WJjF67Eky-f00645.jpg`：两手各比一个"框"角，框内红色区域把人物面部**反相/染色**成红色漫画网点感（红白两色 + 半调）。
- `evidence/comic-frame-BV1WJjF67Eky-f00824.jpg` / `f00866.jpg`：框内出现**红色虚线 + 半透明红色填充**，框随手指移动。
- 风格切换 `X`：红白 ↔ 金色。金色态在 `f00465` 附近的胶囊里，但画面里框仍偏红——**风格切换只改胶囊文字与色点高亮**，画面染色在金色态更偏暖（受视频压缩影响难以确证，记为不确定）。

**机制一句话**：双手四指形成四边形 → 四边形作为**裁切遮罩（clip-path）**，遮罩内对摄像头帧做**双色调/半调后处理**，遮罩边描洋红虚线；开掌=框变大，握拳=框收成点。

**对我们 `frame` 模式的可转化点**：

- 用**四边形顶点=四指指尖**驱动 `clip-path: polygon(...)`，而不是矩形裁剪 → 框可以任意形变。
- 框内做**双色调（duotone）**：把摄像头帧映射到 `ink #1C211A` → `peony #C97F7F` 两色，而不是纯红；这正好落在 contract §6 色板。
- 虚线边 = `stroke-dasharray` 动画，可做"花窗边饰"（A1/A2 藤蔓字标/活体图版）。
- 未就位时给**明确引导文案**（"需要两只手做相框手势"），且胶囊变宽——这是**零学习成本的 onboarding**，对应 B9 手势语法 + B12 全平价。

### 2.2 螺旋星系 / SPIRAL GALAXY（`BV1CDjz6bE6o`）→ 映射 `phyllotaxis`

**顶栏证据**：`strips/BV1CDjz6bE6o-capsule-final.jpg`（f41/f161/f201/f481/f621/f685/f765/f869/f1149/f1189）

- `🖐🖐 螺旋星系`（双掌图标 = 需要两只手）
- `伸出你的手`（提示态，图标换成 `✋`+蓝色斜杠）
- `✊ 握拳→超新星`（握拳触发超新星）
- `流星雨`、`五星星爆`（后续衍生状态）

**视觉行为（证据帧）**：

- `evidence/spiral-supernova-BV1CDjz6bE6o-f00041.jpg`：掌心上方一团**青绿色粒子云**，粒子沿**螺旋臂**分布（对数螺旋），中心亮、外缘稀。
- `f00161.jpg` / `f00201.jpg`：粒子云扩大成**多层螺旋臂**，青绿→白，粒子有**拖尾/连线**（相邻粒子被细线连起，形成"星座"感）。
- `f00481.jpg`：粒子变成**粉紫色**（`#E8C4BE` 附近），绕手腕旋转。
- `f00621.jpg`：**握拳**瞬间，粒子向内坍缩成一点。
- `f00685.jpg`：`握拳→超新星`，粒子**向外爆开**成球形壳，颜色转白/黄。
- `f00869.jpg` / `f01149.jpg`：`流星雨`/`五星星爆` 态，粒子变**黄白色、向下拖长**。
- 粒子数：目测每态 **200–600** 个，尺寸 2–6px，带 additive 发光（screen/lighter 混合）。

**机制一句话**：双掌中心为极点，粒子按**黄金角/对数螺旋**排布成星系；手张开=螺旋放大，握拳=向心坍缩触发超新星（一次 shell burst），随后进入流星雨余波。

**对我们 `phyllotaxis` 的可转化点**：

- 螺旋用 `θ = i·137.5°`（黄金角）+ `r = c·√i`（Vogel 花冠公式）——contract §4 明写"黄金角花瓣螺旋"，此视频正是同一数学。
- **握拳=坍缩→爆发** 是一次性状态机，不是持续粒子；这避免"粒子大杂烩"（contract §6 禁止项）。
- 颜色走 `moss/sage → mist → peony`，不要青绿霓虹（视频里的青绿是反面教材，contract 明令禁止霓虹紫蓝）。

### 2.3 超新星 / 五星星爆（`BV1CDjz6bE6o` 后段 + `BV1GKjm6aEfR`）→ 映射 `spore`

**顶栏证据**：`BV1CDjz6bE6o` 的 `✊ 握拳→超新星`、`流星雨`、`五星星爆`；`BV1GKjm6aEfR` 的 `五星星爆`（f861/f901）。

**视觉行为**：

- `evidence/spiral-supernova-BV1CDjz6bE6o-f00900.jpg`（扫读表 `strips/BV1CDjz6bE6o-scan-late.jpg` f900）：掌上**粉白星尘**，颗粒沿手指方向散开。

**对我们 `spore` 的可转化点**：蒲公英冠毛正是"握拳吹散、开掌接、落地发芽"的现成母题（contract §4 `spore`）；用**扇形角度 = 手指张角**做定向吹散，比随机爆点高级。

## 5. 对 mechanics 的直接结论（可照抄的数值/结构）

1. **胶囊状态机**只有两类文案：`已就位 | 风格 | X切换风格 | fps·ms` 与 `提示语 | fps·ms`。前者两行、后者一行加宽。→ 组件 `StatusCapsule({state, style, fps, ms})`。
2. **fps/ms 是真实读数**：视频里 12–15fps、65–130ms，说明产品**在低端机上诚实降级**并显示出来。contract §11 要求 60/45/30 三档 → 胶囊显示实测值即可。
3. **日志是产品叙事层**：分类色标固定（红/黄/青/绿/紫），行数上限未见（至少 11 行常驻）。建议上限 50 行 + 自动滚动。
4. **颜色点 7 个**，对应 7 种风格/季节 → 与 contract 四季 + 7 模式可做**7 色点=7 季节/风格**，点击即换，键盘 `X` 循环。
5. **左上返回圆**是三支视频唯一的导航元素，且 glyph 随模式变（品牌可变字标）→ A1 自绘藤蔓字标的现成位置。
6. **双拳切模式**是"手势即菜单"，无弹出层 → B9/B14 的极简交互范式。
7. **摄像头三态**至少有 `视图: 摄像头` 日志，`D` 切换 → B15。

## 6. 反模式（视频里有、产品必须改掉的）

- 霓虹青绿/洋红粒子（`#18F0F0`、`#D800F0`）：contract §6 明令禁止霓虹紫蓝。
- `undefined` 泄漏到日志（`切换模式 → undefined`）：必须兜底。
- 全屏摄像头无隐私提示：产品需 B13 隐私仪式（本地处理、不上传、可隐藏）。
- 纯黑胶囊 + 高饱和色点：偏"赛博工具"，产品要改成奶油纸/苔绿体系（contract §6）。
- 只有 640×480 摄像头 + 12–15fps：性能预算 E6 必须给降级路径。

## 7. Limitations（不伪造）

1. **`ripple`（涟漪）与 `mist`（冰雾）在这三支视频中未被观察到**。已做全帧色相扫描（`color-scan.json`：三支视频的 cyan-ness 峰值仅 +1.7/-1.6，无青色主导帧）与全部 9 张接触表 + 42 张关键帧扫读，未发现水面涟漪或冷凝雾面画面。contract §4 把这两个模式归因于"视频「涟漪」/「冰雾」"，但**下载到的三支视频不含这两段**。→ 这两个模式的视觉参考改由 `botanica-gif`（水滴/玻璃质感）与 OPL atlas 提供；mechanics 不应把视频当唯一依据。
2. 视频含 Windows 任务栏、浏览器地址栏、鼠标指针，**画面区域有遮挡**；所有 UI 读数均来自放大裁切，个别小字（如 ms 读数）可能有 ±1 误差。
3. 粒子数量、线宽等为**目测估计**，非逐像素测量。
4. `涂鸦` 模式切换后立即回退，未获得画面证据。
5. 三支视频是同一产品的不同版本，**UI 细节（胶囊宽度、glyph、日志文案）不一致**；本文以出现次数最多的形态为准，差异在各节注明。
6. 无音频轨分析（三支视频均为纯画面演示，未做声景拆解）。
