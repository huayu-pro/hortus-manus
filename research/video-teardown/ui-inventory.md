### 1.1 色点（Style Dots）

| 3 | `#D800F0` | 洋红 | |

选中态 = 该色点外圈套一个**白色细环**（`BV1CDjz6bE6o-capsule-final.jpg` f41 第 2 点）。

### 1.2 fps/ms 读数

- 格式：`NNfps·NNms`（中点分隔，无空格）。
- 实测范围：**12–15 fps，65–130 ms**。三支视频**从未超过 15fps** —— 这是低端笔记本 + 640×480 摄像头的真实性能。
- 这是产品里**最诚实**的元素：直接暴露性能，而不是假装 60fps。contract §11 的 60/45/30 三档应显示实测值。

## 8. 可复用 vs 需重写（给 stage/atelier 的清单）

**可复用（结构级）**
1. 顶栏胶囊的两行结构（状态 + 性能读数）。
2. 7 色点 + 清空键的横向工具条。
3. 左上模式化品牌 glyph 返回键。
4. 左下事件流日志（时间戳 + 分类色标）。
5. 全屏镜像摄像头舞台。
6. 引导态文案（"需要两只手…"/"伸出你的手"）替换主文案的**同一胶囊槽位**。

**必须重写（风格级）**
1. 纯黑胶囊 + 霓虹色点 → 奶油纸/苔绿/芍药粉（contract §6）。
2. 等宽终端日志 → 保持等宽但换成 IBM Plex Mono + 纸色底 + 边注式排版（A9 边注系统）。
3. 赛博粒子 → 植物学粒子（花瓣/孢子/菌丝）。
4. 12–15fps 无降级 → E6 性能预算三档。
5. `undefined` 泄漏 → 兜底 + 不伪造。
6. 无隐私提示 → B13 隐私仪式（本地处理声明 + 摄像头可隐藏）。
