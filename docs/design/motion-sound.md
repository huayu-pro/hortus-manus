# HORTUS MANUS · 指间花园 — 动效与声景规范 Motion & Sound v1

> Owner: atelier。实现归 mechanics / stage；本文只定**意图、时长、曲线、触发、终态**。
> 所有时长/曲线必须取自 `tokens.css` 的 `--hm-dur-*` / `--hm-ease-*`；所有文案取自 `copy.ts`。
> 原则：**慢而重，一次性，有终态**。植物不会闪；花园不催人。

---

## 1. 动效原则（先读这五条）

1. **慢而重**：UI 反馈 90–360ms；文本 720ms；图像 960ms；花开 1600–2400ms；转场 1200–3200ms。低于 90ms 的只有按下反馈。
2. **一次性入场**：每幕/每块只入场一次，滚动回看不重播（用 `IntersectionObserver` + `once` 标记）。禁止无限扫光、呼吸闪烁、自动轮播。
3. **只动四个属性**：`transform`、`opacity`、`clip-path`、`filter`。不改 layout（width/height/top/left），避免重排。
4. **每个动效都有终态**：动画结束后的静止构图必须是完整、可读、可操作的；动画只是「到达」的方式，不是内容。
5. **reduced-motion 不是关掉一切**：是把「过程」压缩为 0，直接呈现终态；状态、颜色、层级、可读性一律不变。

**方向隐喻**：纸是**从上落下**的；花是**从下开**的；雾是**从边缘退**的；墨是**从中心洇**的；读数**直接替换**（不跳字）。

| `--hm-dur-4` | 360ms | UI 状态切换、面板展开 |
| `--hm-dur-5` | 480ms | 标签/光标/擦痕、HUD 淡出、toast 退出 |
| `--hm-dur-6` | 720ms | 文本入场、图版淡入 |
| `--hm-dur-7` | 960ms | 图像揭示、锚点滚动 |
| `--hm-dur-8` | 1200ms | 墨/花瓣转场、模式 dissolve、换季材质 |
| `--hm-dur-9` | 1600ms | 花开（单层） |
| `--hm-dur-10` | 2000ms | 花瓣落、长 dissolve |
| `--hm-dur-11` | 2400ms | 花开（全开）、舞台形态切换 |
| `--hm-dur-12` | 3200ms | 幕转场床、退出温室、尾幕淡出 |
| `--hm-dur-ambient` | 32000ms | 环境循环（活时钟、萤火漂移） |

| 曲线 | 值 | 用途 |
|---|---|---|
| `--hm-ease-standard` | cubic-bezier(.2,.7,.3,1) | 默认 UI |
| `--hm-ease-out` | cubic-bezier(.16,.84,.28,1) | 入场、揭示 |
| `--hm-ease-in` | cubic-bezier(.7,.02,.3,1) | 退场 |
| `--hm-ease-bloom` | cubic-bezier(.12,.86,.18,1) | 花开、植物生长 |
| `--hm-ease-ink` | cubic-bezier(.77,0,.18,1) | 墨洇、转场 |
| `--hm-ease-press` | cubic-bezier(.34,1.36,.64,1) | 印章（唯一允许轻微过冲） |
| `--hm-ease-linear` | linear | 时钟指针、进度 |

**禁止的曲线**：bounce/elastic 全局使用（仅印章可用一次过冲）、steps() 做闪烁、超过 3 次重复的循环。

## 4. `prefers-reduced-motion` 终态表

`tokens.css` 已把 `--hm-dur-*` 置 0。以下是**每个动效必须实现的终态**（CSS/JS 都要保证；不能只依赖全局 `animation-duration: 0.01ms` 兜底）。

| 动效 | reduced-motion 终态 | 实现要点 |
|---|---|---|
| M01 页面入场 | 直接完整页面 | 无 `opacity:0` 初始态残留 |
| M02 文本逐行 | 全部行在位 | 不设置初始 `translateY`，用 `@media` 覆盖 |
| M03 图版揭开 | 图版完整显示 | `clip-path: none` |
| M05 章节轨 | 直接切换实心 | 无过渡 |
| M07 活时钟 | 指针静止在真实位置，每 60s 跳一次 | 不逐秒动画 |
| M08 转场 | 直接切换新幕 | 无遮罩动画；遮罩不出现 |
| M09 滚动编排 | 所有元素已在终态 | 错峰延时归 0 |
| M12 放大镜 | 镜片直接出现，无淡入 | 保留放大功能 |
| M21 花开 | 花直接全开或回苞 | 状态由手势驱动，不靠动画中间帧 |
| M22 花瓣落 | 花瓣已在纸面 | 直接渲染终态 |
| M23 丝线 | 物理仍实时（这是内容，不是装饰） | 保留 Verlet；不加额外缓动 |
| M24 露珠 | 静止在节点 | 不滑动 |
| M25 涟漪 | 直接显示最终一圈淡痕，1.5s 后消失 | 不用扩散动画 |
| M26 孢子 | 直接显示空茎 + 落地种子 | 不飞散 |
| M27 菌络 | 网络直接完整生长 | 不逐段生长 |
| M28 晨雾 | 擦除即时生效；雾不自动回 | 保留交互，去掉时间轴 |
| M30 幽灵手 | **不自动播放**；仅在用户按 G 时静态显示手形 + 当前模式 | 自动演出关闭 |
| M31 手势确认 | 直接变选中态 | 无脉冲 |
| M32 采集 | 直接出现采集卡 | 无压缩动画 |
| M40–M50 | 直接切换终态 | 无位移/缩放（按下也不缩放） |
| M51 HUD 静置 | 不降透明度 | 保持 100% |
| M53 退出 | 直接回到 `/` | 无遮罩 |

**判断标准**：打开系统「减少动态效果」后，逐页截图与正常模式**构图一致**，只有过程消失；内容、状态、可读性无任何损失。JS 动画（Motion / rAF）必须读 `matchMedia('(prefers-reduced-motion: reduce)')` 并在变化时实时切换。

**另外两条**：
- 舞台物理（Verlet、涟漪、螺旋）属于**内容**而非装饰，reduced-motion 下保留，但不加额外缓动/镜头运动。
- 任何「自动播放」类行为（幽灵手自动演出、环境漂移）在 reduced-motion 下默认关闭。

## 5. 声景（D5）

### 5.1 总策略

- **默认静音**。首次进入不发声；只有用户点击「声音」或按 `S` 才启动 WebAudio（满足自动播放策略）。
- 全部**实时合成**，无音频文件（E4：运行时 0 外网）。
- 音量上限：主输出 ≤ −18 dBFS 常态，峰值 ≤ −6 dBFS；不出现刺耳高频（>8kHz 衰减）。
- 关闭时淡出 480ms 后 `suspend()`；开启时 `resume()` + 480ms 淡入。
- 偏好持久化：`localStorage: hm:sound = "on" | "off"`；下次进入若为 on，仍需**一次用户手势**才真正发声（在首屏按钮/推门时恢复）。
- 页面切到后台：自动降到 0（`visibilitychange`），回来淡入 720ms。
- 不因换主题、换季、切换模式而中断；只改变层权重。

### 5.2 四层结构

| 层 | 声音意象 | 合成方式 | 触发 | 默认权重 | 频率范围 |
|---|---|---|---|---|---|
| **风 WIND** | 温室里的穿堂风 | 白噪 → 带通（200–900Hz，Q 0.7）+ 缓慢 LFO 调制增益 | 常驻（声音开启时） | 0.45 | 低频为主，无嘶声 |
| **水 WATER** | 池面、露珠、玻璃上的水 | 粉噪 → 低通 1.2kHz + 随机短脉冲（水滴：短包络 + 带通 1.5–3kHz） | 常驻低权重；RIPPLE/MIST 模式升权 | 0.25 | 中频，湿润 |
| **丝弦 SILK** | 翻绳的张力、丝线振动 | Karplus-Strong 拨弦（延迟线 + 低通反馈），音高随丝线张力 | TENDRIL 模式；手势拉紧时触发 | 0.2（仅该模式） | 300–1200Hz 基频 |
| **五声音阶 PENTATONIC** | 花开、采集、季节 | 加法合成（正弦 + 少量泛音），音阶为宫商角徵羽（C D E G A），每次只发一个音 | 事件型：花开、采集、致谢、换季 | 0.1（事件） | 500–2000Hz |

**五声音阶规则**：
- 音阶固定 `C4 D4 E4 G4 A4 C5 D5 E5 G5 A5`（10 音），每次事件随机取一个，**同音不连续两次**。
- 花开 = 上行二度/三度；采集 = 纯五度下行；换季 = 该季节固定音（春 E、夏 A、秋 D、冬 C）。
- 单音时长 600–1200ms，包络 attack 120ms / release 800ms；不叠加超过 2 个同时发声的音。
- 绝不做旋律化自动演奏；不做「音乐」，只做「花园的回声」。

### 5.3 层权重表（按模式）

| 模式 | 风 | 水 | 丝弦 | 五声 |
|---|---|---|---|---|
| frame 花窗 | 0.5 | 0.2 | — | 花开事件 |
| tendril 翻绳 | 0.4 | 0.1 | **0.4** | 采集事件 |
| ripple 雨池 | 0.3 | **0.5** | — | 涟漪事件（轻） |
| spore 孢子 | **0.6** | 0.1 | — | 吹散事件 |
| mycelium 菌络 | 0.4 | 0.2 | 0.1 | 脉冲事件（4s） |
| mist 晨雾 | 0.35 | **0.45** | — | 擦窗事件 |
| phyllotaxis 花冠 | 0.45 | 0.15 | 0.1 | 旋转事件（稀疏） |

权重过渡 720ms，线性交叉，不做突变。

### 5.4 交互反馈音（微声）

| 事件 | 声音 | 时长 | 音量 |
|---|---|---|---|
| 按钮按下 | 极短木质点击（带通 800Hz，包络 40ms） | 90ms | −30 dBFS |
| 模式切换 | 丝弦轻拨（该模式音高） | 480ms | −26 dBFS |
| 采集 | 纯五度下行 + 纸页摩擦（噪声包络 300ms） | 1200ms | −20 dBFS |
| 致谢 | 单音 + 轻微混响 | 800ms | −24 dBFS |
| 换季 | 该季固定音 + 风声变化 | 2000ms | −22 dBFS |
| 错误 | **不发声**（避免惩罚感）；只视觉提示 | — | — |
| 焦点移动 | 不发声（键盘用户不应被声音轰炸） | — | — |

### 5.5 声景可访问性

- 声音开关必须可键盘操作（`S` 与按钮），状态有 `aria-pressed` 与可见文字。
- 提供「静默模式」`quiet`：关闭所有非必要声音，仅保留采集确认（可再关）。
- 不依赖声音传达必要信息（状态一律有视觉/文字）。
- 不做空间音频定位（避免眩晕）；不做 3D 声场。

### 5.6 触觉（D6，移动端）

- 采集成功：`navigator.vibrate?.(12)`；致谢：8ms；错误：不振动。
- 仅移动端、仅在用户已交互后；`prefers-reduced-motion` 不影响振动（可单独设置关闭）。
- 不使用连续振动/节奏振动。

## 6. 性能预算（与动效相关）

| 指标 | 目标 | 降级 |
|---|---|---|
| 舞台帧率 | 60fps | <45fps 连续 2s → 降粒子数/关闭 grain 动画/降低 DPR 至 1 |
| 动效属性 | 仅 transform/opacity/clip-path/filter | 降级时去掉 filter（模糊/投影） |
| 同时动画元素 | ≤24 个 | 超限时合并（错峰改为同帧） |
| 首次入场总时长 | ≤ 2400ms | 慢网/低端机 → 直接终态 |
| 声音启动延迟 | ≤ 200ms | — |
| 长任务 | 无 >50ms 主线程阻塞 | 图版解码用 `createImageBitmap` |

**降级规则**：低端设备（`navigator.hardwareConcurrency ≤ 4` 或 `deviceMemory ≤ 4`）默认关闭 grain 动画、花瓣数减半、幽灵手演出缩短到 6s。

## 7. 验收清单

1. 所有动效时长/曲线来自 token，无硬编码 `0.3s`。
2. 每幕入场只播一次；回滚不重播。
3. `prefers-reduced-motion` 下逐页与正常模式构图一致（截图对比）。
4. 无无限循环动效（活时钟与夜间萤火除外，且 reduced-motion 静止）。
5. 无自动播放声音；首次发声必须由用户手势触发。
6. 声音关闭后 `AudioContext` 进入 suspended；页面隐藏时静音。
7. 采集→致谢→换季三类事件各有一个可辨识的声音，且不刺耳。
8. 60fps 下无掉帧尖峰；降级路径可手动触发验证。
9. 触觉只在移动端且只在成功事件触发。
10. 动效不阻塞输入：动画期间按钮可点、可聚焦。

*动效与声景是「花园的呼吸」，不是装饰。任何新增动效必须先回答：它的终态是什么？reduced-motion 下还剩什么？*
